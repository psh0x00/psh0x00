### 🚀 Featured Projects
*   **[JobPulse](https://github.com/psh0x00/JobPulse)** ([Live Demo](https://jobpulse-production-bd49.up.railway.app/)): A production-grade REST API built with Java 21 and Spring Boot 4 to track job applications, interviews, and follow-ups. Features include JWT authentication, Redis caching, scheduled background tasks, and a full CI/CD pipeline with GitHub Actions. Deployed live on Railway with a multi-stage Docker build.
*   **[Workflow Engine](https://github.com/psh0x00/gestor-workflow)**: An enterprise-grade engine built with C# .NET Core and SQL Server, leveraging Finite State Machines (FSM) for granular management of transitions, pre/post-conditions, and RBAC permissions.
*   **[WardrobeManager](https://github.com/psh0x00/WardrobeManager)**: A Docker-orchestrated platform featuring an asynchronous FastAPI backend and PostgreSQL schema migrations (Alembic), exposing analytics endpoints and automated CSV dataset export.
*   **[CampusServiceManagement](https://github.com/psh0x00/CampusServiceManagement)**: An offline-first Android application (Kotlin / Clean Architecture / MVVM) featuring resilient bidirectional synchronization between Room (SQLite) and Firebase via WorkManager.
